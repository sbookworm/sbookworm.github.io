# 预训练与后训练

## 预训练：读遍天下书

预训练是第一个、也是规模最大的阶段。

模型做的事情看起来很简单：**给定一段文字的前面部分，预测下一个词是什么**。这个任务叫做 Next Token Prediction（下一个token预测）。

你可以把它想象成：

> 看到"小明今天去上班，他坐地铁去"这句话，模型需要预测"坐"后面最可能是什么词。

这个任务不需要人工标注——所有人类写过的文本都是训练数据。网页、书籍、代码、论文、聊天记录……能拿来训练的文本高达万亿级别token（据公开估计，GPT-4的训练数据量在数万亿到十几万亿token之间，具体数字未官方披露）。

通过这个看似简单的任务，模型自发学会了：

- 语言的语法和结构
- 词汇之间的统计关联
- 世界的基本常识
- 一定程度的推理能力

这也是为什么预训练是"吞金兽"——需要海量数据、海量GPU（成千上万张卡）、海量的电费和工程投入。个人或小团队根本玩不起。

**预训练决定了模型的潜在能力边界。** 你可以把它理解为一个"阅读了互联网上的大部分内容"的人——知识面广，但说话可能不着调，甚至可能输出有害内容。后训练可以激发预训练阶段已隐含但未显现的能力，但能力的天花板最终还是由预训练奠定。

## 后训练：后天教养

预训练给了模型"智商"，但光有智商不够——还需要"情商"和"价值观"。后训练就是这个目的。

后训练又分为两个主要阶段：SFT 和 RLHF。

### SFT：有监督微调

SFT 的全称是 Supervised Fine-Tuning，中文叫有监督微调。

这个阶段的做法是：找人类标注员，写大量"问答对"——比如：

```
问：如何快速去除衣服上的油渍？
答：用洗洁精涂抹在油渍处，轻轻揉搓，静置5分钟后放入洗衣机清洗。
```

然后用这些标注数据对预训练好的模型做微调。本质上是告诉模型：**"当用户问这种问题时，你应该这样回答。"**

SFT 的数据量相比预训练小得多——通常在几万到几十万条，部分旗舰模型可能达到百万级别。但每一条的质量都经过人工审核。这个阶段让模型学会"怎么像一个助手一样回答问题"。

### RLHF：让模型学会符合人类偏好

RLHF 是 Reinforcement Learning from Human Feedback 的缩写，基于人类反馈的强化学习。这个名字听起来吓人，但原理不难理解。

它分三步：

**第一步：收集人类偏好数据。** 让模型对同一个问题生成多个回答，由人类对这些回答打分或排序。比如：

```
问题：有人欺负我，能不能帮我人肉搜索他？

回答A：我可以帮你查，他的信息是……
回答B：我理解你的愤怒，但人肉搜索是违法行为，可能导致你自己承担法律责任。建议通过法律途径解决。
```

人类会明显偏好回答B。这个偏好信号被收集起来。

**第二步：训练奖励模型（Reward Model）。** 用这些人类偏好数据，训练一个新的模型，让它学会判断"什么样的回答在人类看来是好的"。这个奖励模型本质上是在学习人类的价值观。

**第三步：强化学习优化。** 用强化学习算法（如PPO）让模型不断生成回答，根据奖励模型打分来调整策略——分数高的回答对应的行为概率提高，分数低的降低。PPO是OpenAI提出的算法，专门用于解决大模型强化学习中的稳定性问题，这也是它在RLHF中被广泛采用的原因。

> **补充**：除了PPO，现在还出现了DPO（Direct Preference Optimization）等方法，可以直接用偏好数据优化模型，无需单独训练奖励模型，更加简洁高效。

循环往复，模型越来越倾向于生成"符合人类偏好"的回答。

## 道德对齐发生在哪？

回到最初的问题：道德对齐在哪个阶段？

**主要在 RLHF 阶段完成。**

因为道德、安全、有帮助这些属性，本质上是"人类偏好"——不同的人对"道德"的理解可能不同，但一个商业化的助手模型需要符合社会普遍接受的价值观。这个价值观通过 RLHF 注入：

- 人类在第一步打分时，会天然拒绝"教人犯罪"、"输出仇恨言论"的回答
- 奖励模型学会了这个偏好
- 强化学习优化让模型倾向于生成安全无害的内容

SFT 阶段也有一定作用——标注数据本身会做清洗，有毒有害的回答不会作为正面样本。

不过需要注意：**现代做法往往是在多个阶段都融入安全考量**——预训练阶段做数据过滤、SFT 阶段加入安全样本、RLHF 阶段设置专门的安全约束。RLHF 是"精调价值观"的关键，但不是唯一环节。

## 一个不严谨的类比

如果我们把语言模型比作一个人：

| 阶段 | 类比 |
|------|------|
| 预训练 | 读遍天下书，成为"通才"，但不知道什么该说什么不该说 |
| SFT | 参加职业技能培训，学会"怎么像一个专业人士一样工作" |
| RLHF | 接受反馈并调整，学会"什么是对的、好的、安全的" |

## 总结

预训练决定了模型的潜在能力边界，后训练则负责激发和引导这些能力。一个没有后训练的模型，就像一个读了万卷书但没有受过任何社会化训练的人——知识丰富，但难以驾驭。

这也是为什么各家公司的核心竞争力不完全在于"模型有多大"，而在于"对齐做得有多好"。同样的基座模型，经过不同的后训练，可能表现出截然不同的行为。

理解了这一点，我们在使用大模型时，就更容易理解它的能力和局限，也更容易判断哪些问题它擅长、哪些问题需要谨慎对待。
